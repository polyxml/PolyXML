# Ecosystem Compatibility Audit — Wave 9 (50-item modern ecosystem deep dive) — 2026-11-20

Fifty previously unaudited open issues and recently closed/merged PRs were audited against PolyXML checkout `7d8ee3d` (CLI `0.40.0`) across **13 repositories** spanning all 7 target ecosystems: `Bergmann89/xsd-parser`, `tefra/xsdata`, `mganss/XmlSchemaClassGenerator`, `sissaschool/xmlschema`, `dapper91/pydantic-xml`, `tafia/quick-xml`, `NaturalIntelligence/fast-xml-parser`, `eclipse-ee4j/jaxb-ri`, `FasterXML/jackson-dataformat-xml`, `media-io/yaserde`, `highsource/jaxb-tools`, `hooklift/gowsdl`, and `xuri/xgen`.

All 179 upstream references already covered in Waves 1–8 (`research/ecosystem-audits/*.md` and prior closed `polyxml/PolyXML` issues) were excluded programmatically. Modern language idioms (Python 3.12+ `type` / `StrEnum`, Rust zero-copy `quick-xml`, Java 22+ records / sealed interfaces / StAX, C++20 `std::variant` / `std::from_chars`, TypeScript 5+ `as const` unions) were prioritized, while legacy compatibility shims (`xsd.exe`, `javax.xml.bind`, Python 3.9/3.10 fallbacks) were rejected by design.

Minimal test schemas are saved under [`tests/fixtures/conformance/wave9/`](../../tests/fixtures/conformance/wave9/).
